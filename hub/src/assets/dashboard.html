📁 Deployment Instructions (No manual input needed in EA):
  1. Click ⬇️ Download Key File below to save copier_hub.key.
  2. In MT4 / MT5, click File → Open Data Folder.
  3. Place copier_hub.key into:
    • MQL4\Files\ (for MT4) or MQL5\Files\ (for MT5), OR
    • Terminal\Common\Files\ (shared across ALL MT4/MT5 terminals on this computer!).
  4. Attach CopierSender or CopierReceiver with Mode = Central (Hub). The EA automatically detects and loads the key file!
